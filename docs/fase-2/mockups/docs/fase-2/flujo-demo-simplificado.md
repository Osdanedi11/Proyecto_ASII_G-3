# Flujo de demostración simplificado

Duración sugerida: 12 a 15 minutos.

## 1. Acceso y estructura común

1. Abra `/login` y muestre que todo el acceso cabe en una pantalla.
2. Seleccione un rol; el correo ficticio se completa sin exponer una contraseña real de usuario.
3. Ingrese y señale la navegación orientada a tareas, las migas y la identidad del rol.
4. En móvil, abra y cierre el menú; en escritorio, colapse la barra lateral.

## 2. Estudiante — 3 minutos

1. Ingrese como Valeria Mora.
2. Desde Inicio, use **Continuar tarea**.
3. Cambie el estado y confirme el mensaje de éxito.
4. Publique un comentario y adjunte un PDF pequeño.
5. Abra Notificaciones y luego Configurar; cierre el modal con Escape.

Resultado visible: cambian la tarea y el progreso; aparecen comentario, evidencia, notificación y bitácora.

## 3. Líder de equipo — 3 minutos

1. Ingrese como Camila Vargas.
2. Cree un proyecto desde **Proyecto actual**.
3. Abra **Tareas**, cree una responsabilidad y luego edite su fecha o prioridad.
4. Consulte **Equipo**, **Cronograma** e **Historial**.

Resultado visible: proyecto, cronograma, tarea, notificación e historial quedan actualizados en memoria.

## 4. Profesor — 2 minutos

1. Ingrese como Andrea Chaves.
2. Abra **Revisiones** y seleccione una evidencia.
3. Muestre el tipo de archivo y tamaño en lenguaje natural; registre retroalimentación.
4. Abra **Evaluaciones**, guarde y confirme una calificación.
5. Genere el PDF desde **Reportes**.

Resultado visible: comentario y evaluación registrados, con trazabilidad.

## 5. Administrador — 2 minutos

1. Ingrese como Mauricio Rojas.
2. En **Usuarios**, cree una cuenta ficticia.
3. Cambie un rol o active/desactive una cuenta y confirme la acción.
4. Consulte **Actividad**.

Resultado visible: cuenta y evento administrativo nuevos.

## 6. Auditor — 2 minutos

1. Ingrese como Laura Jimenez.
2. Abra **Bitácora** y combine filtros.
3. Abra un evento; señale el identificador, usuario, módulo, fecha y resumen.
4. Confirme que no hay controles de edición y genere el JSON de auditoría.

Resultado visible: consulta y exportación sin mutar ningún registro.

## Cierre

Recargue la aplicación para explicar que el estado vuelve a los datos ficticios originales: es una limitación
intencional del prototipo, no una persistencia productiva.
